## Health and search behavior

- Search runs the enabled Internet Archive, Audius, and YouTube Data API providers in parallel, and Jamendo in parallel when configured. One provider failure is reported independently and does not discard other providers' results.
- Results show their source provider, are deduplicated when title/artist/album/duration identify the same recording, and distinguish authorized audio streams from metadata-only results. YouTube metadata never enters the audio resolver.
- `/api/providers/health` tests enabled provider endpoints and reports search/playback support, credential needs, the last successful check, and provider errors. YouTube health checks skip billable searches; live searches verify its API key. Last-success timestamps are held in API process memory.
- The search UI distinguishes no results, provider errors, missing Jamendo credentials, and results unavailable for playback. Selecting a YouTube result searches authorized audio sources and surfaces match/search failures without redirecting.
- Provider controls show result counts for the current page; provider health reports YouTube as metadata search only, and otherwise `Connected`, `Search Only`, `Playback Supported`, `Credentials Missing`, `Unsupported`, or a connection failure as appropriate.

## Validation performed

- Audius live search returned a genuine track; live combined search returned provider results successfully.
- Playwright verified actual Audius playback, seek, pause, and resume, plus Internet Archive playback advancement on mobile. The desktop Archive test waiting beyond 30 seconds encountered a Chromium crash, so longer desktop playback and seek were not verified in this run.
- Official YouTube Data API v3 searches for Pal Pal, Aarzu, Kesariya, Tum Hi Ho, and Believer returned genuine metadata including video IDs and durations. No exact normalized title-and-artist match was found in the authorized provider results for the top result of each query. These checks do not establish YouTube audio playback.
- Unit tests cover provider failure isolation, metadata mapping, credential secrecy, restricted Audius tracks, deduplication/source attribution, and provider health.
- Jamendo playback remains unverified. No live SoundCloud or Spotify requests were made because they are disabled for the policy limitations above.
- YouTube results do not link out automatically. Authorized audio matching and real playback must be verified independently for each queried title and artist.
