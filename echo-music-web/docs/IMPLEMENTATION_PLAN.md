# Implementation Plan

1. Audit complete Android source and map feature boundaries.
2. Create separate React/TypeScript frontend and Express backend.
3. Build shared HTML5 playback, persistent library, search, queue, lyrics, and responsive shell.
4. Add provider adapters only for authorized external APIs.
5. Add focused unit and browser tests.
6. Document browser/OS/native limitations honestly.
7. Expand advanced provider-backed features incrementally after credentials and protocol details are supplied.
